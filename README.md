# Joyeuse Uwera — Portfolio Website

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Open locally
1. Extract this ZIP file.
2. Open the `Joyeuse_Portfolio` folder.
3. Double-click `index.html` or open the folder in VS Code and use Live Server.

No package installation is required.

## Before publishing
Please review these items:
- Add your professional email in the Contact section.
- Replace illustrative project visuals with real screenshots or Figma prototype links where you have them.
- Confirm the project descriptions match what you personally built or contributed to.
- Add your recovered LinkedIn profile URL after you regain access.
- Check every link and spelling detail.

## Publish for free with GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `joyeuse-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to provide your live website URL.

You can also deploy the folder using a static-hosting service such as Vercel or Netlify.

## Notes
